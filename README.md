# नेमिधाम मंदिर वेबसाइट: बदलाव कैसे करें (आसान गाइड)

यह फ़ाइल सिर्फ़ एक काम के लिए है: **वेबसाइट पर कुछ बदलना, जोड़ना, हटाना या छुपाना।** कोडिंग आना ज़रूरी नहीं है।

**कैसे पढ़ें:** पहले भाग 1 और 2 एक बार पढ़ लो (5 मिनट). फिर जब भी कुछ बदलना हो, भाग 3 की तालिका में देखो कि वह कहाँ है, और भाग 5 में उसके स्टेप पढ़ो।

---

## 1. पहले ये 3 बातें समझ लो

1. **वेबसाइट की लगभग सारी जानकारी एक ही फ़ाइल में है: `js/data.js`.** समय, सूचना, कार्यक्रम, योजना, टीम, दान, फ़ोटो, सब इसी में है।
2. **हर लिखावट दो भाषाओं में होती है:** `hi` (हिंदी) और `en` (English). कुछ भी नया जोड़ो तो दोनों भरो।
   ```
   title: { hi: "यहाँ हिंदी", en: "Here English" }
   ```
3. **दो छोटे जादुई शब्द:**

| शब्द | क्या करता है |
|---|---|
| `hidden: true,` | उस चीज़ को वेबसाइट से **छुपा देता है** (मिटाता नहीं)। यह लाइन हटाओ तो चीज़ वापस दिखेगी। |
| `pinned: true,` | उस चीज़ को **Home पेज पर भी** दिखाता है (योजना, कार्यक्रम, सूचना के लिए)। लाइन हटाओ तो Home से हट जाएगी, अपने पेज पर बनी रहेगी। |

---

## 2. बदलाव करने का तरीका (हर बार यही)

### 2.1 सात स्टेप

1. **GitHub खोलो**, login करो, अपना रिपॉज़िटरी `Nemidham` खोलो।
2. फ़ोल्डर **`js`** → फ़ाइल **`data.js`** खोलो।
3. ऊपर दाईं तरफ़ **✏️ पेंसिल** दबाओ।
4. फ़ाइल के अंदर एक बार क्लिक करो, फिर **Ctrl + F** दबाकर वह नाम ढूँढो जो भाग 3 में बताया है (जैसे `window.EVENTS`). मोबाइल पर browser के मेन्यू में "Find in page" चुनो।
5. बदलाव करो (नीचे के नियम देखो)।
6. ऊपर दाईं तरफ़ हरा **"Commit changes..."** दबाओ, फिर दोबारा **"Commit changes"**.
7. **1-2 मिनट रुको**, वेबसाइट खोलकर **Ctrl + Shift + R** दबाओ (मोबाइल पर browser का cache साफ़ करो)।

### 2.2 लिखने के नियम (सबसे ज़रूरी)

- टेक्स्ट हमेशा **"दोहरे quote"** के अंदर रहे।
- हर चीज़ के आख़िर में **कॉमा ( , )** रहे।
- हर चीज़ `{ ... },` के **डिब्बे** में होती है। डिब्बा हमेशा **पूरा** कॉपी करो (`{` से `},` तक), आधा नहीं।

### 2.3 जोड़ना, हटाना, छुपाना: हर जगह एक ही तरीका

सूचना, कार्यक्रम, योजना, टीम का समूह, "हमारे बारे में" का हिस्सा, कैसे पहुँचें का डिब्बा, नियमित दान का कार्ड, गैलरी एलबम, कैलेंडर की तारीख़, सबमें:

- **नया जोड़ना:** उसी सूची का एक पूरा डिब्बा कॉपी करो, उसी के नीचे पेस्ट करो (दो डिब्बों के बीच कॉमा रहे), और टेक्स्ट बदलो। जिस डिब्बे में `id` है, उसकी `id` नई और अलग रखो (English छोटे अक्षर, बिना space).
- **हटाना:** पूरा डिब्बा मिटा दो।
- **कुछ समय के लिए छुपाना:** डिब्बे में `hidden: true,` जोड़ दो। फिर दिखाना हो तो वह लाइन मिटा दो।

**सबसे आम ग़लती:** कॉमा छूट जाना, quote बंद न होना, या डिब्बा आधा कॉपी होना। ऐसा हो जाए तो भाग 7 देखो।

## 4. फ़ोटो या फ़ाइल कैसे डालें

फ़ोटो, QR, लोगो जैसी फ़ाइलें `images` फ़ोल्डर में जाती हैं।

1. GitHub में रिपॉज़िटरी खोलो और सही फ़ोल्डर में जाओ (जैसे `images` या `images/team`).
2. ऊपर **Add file → Upload files** दबाओ।
3. फ़ोटो खींचकर (drag) वहाँ छोड़ दो।
4. नीचे **Commit changes** दबाओ।
5. फ़ाइल का **नाम** याद रखो (जैसे `ramesh.jpg`). यही नाम `data.js` में लिखना है।

> नाम छोटा, English अक्षरों में, बिना space का रखो: `ramesh.jpg`. "Ramesh ji photo 1.jpg" नहीं।

### ⚠️ फ़ोटो हमेशा पहले छोटी (resize) करके ही डालो

मोबाइल या कैमरे की फ़ोटो 3-8 MB की होती है। इतनी बड़ी फ़ोटो से GitHub पर upload में **error** आता है ("Commit failed", "file is too large", error 400) और वेबसाइट **धीमी** खुलती है।

**BIRME से छोटी करो** (`birme.net`, free, login नहीं चाहिए, एक साथ बहुत सारी फ़ोटो):
1. ब्राउज़र में `birme.net` खोलो।
2. सारी फ़ोटो एक साथ खींचकर वहाँ छोड़ दो।
3. **Width** में `1600` लिखो (Height खाली या auto), Quality `75` से `80`, format JPG.
4. **Save as Zip** दबाओ, zip को खोलो (unzip) और **अंदर की फ़ोटो** GitHub पर डालो।

इससे हर फ़ोटो लगभग 300-500 KB की रह जाती है और 50 फ़ोटो भी 15-25 MB में आ जाती हैं। (BIRME न खुले तो Windows में **PowerToys → "Resize pictures"** भी यही करता है।)

**GitHub पर डालते समय:**
- एक बार में **15-20 फ़ोटो** ही डालो, Commit करो, फिर अगली 15-20.
- एक फ़ाइल 25 MB से बड़ी न हो।

## 5. काम-दर-काम स्टेप

(हर काम में भाग 2.1 के स्टेप 1 से 4 पहले, और स्टेप 6-7 आख़िर में करने हैं। जोड़ने/हटाने/छुपाने का तरीका भाग 2.3 में है।)

### 5.1 नई सूचना (Announcement)

1. ढूँढो: `window.ANNOUNCEMENTS`
2. एक डिब्बा कॉपी करके नीचे पेस्ट करो। हर डिब्बा ऐसा है:
   ```
   {
     date: "2026-10-26", pinned: true,
     title: { hi: "...", en: "..." },
     text:  { hi: "...", en: "..." }
   },
   ```
3. `date` (साल-महीना-दिन), `title`, `text` बदलो (हिंदी और English).
4. **Home पर भी दिखाना है** तो `pinned: true`. सिर्फ़ सूचनाएँ पेज पर दिखाना है तो `pinned: false`.

### 5.2 नया कार्यक्रम (Karyakram)

1. ढूँढो: `window.EVENTS`
2. नीचे `hidden: true` वाला एक तैयार साँचा (template) है जिसमें "SAMPLE" लिखा है। उसकी `hidden: true,` लाइन हटाओ और टेक्स्ट बदलो। या किसी भी डिब्बे को कॉपी करो।

| लाइन | क्या लिखना है |
|---|---|
| `date: "2026-11-09"` | तारीख: साल-महीना-दिन |
| `endDate` | सिर्फ़ तब, जब कार्यक्रम कई दिन चले |
| `time` | समय, जैसे `{ hi: "सुबह 7:00", en: "7:00 AM" }` |
| `place`, `type` | जगह, और किस्म (उत्सव, पूजा...) |
| `title`, `text` | नाम और थोड़ी जानकारी |
| `pinned: true,` | Home पर भी दिखाने के लिए (अगले 3 आने वाले pinned कार्यक्रम दिखते हैं) |

पुराने कार्यक्रम अपने आप "पुराने" टैब में चले जाते हैं और 30 दिन बाद हट जाते हैं। दिन बदलने हों तो `window.SITE` में `karyakramPastDays` की संख्या बदलो (`-1` = कभी नहीं हटेंगे).

### 5.3 योजना (Yojana)

1. ढूँढो: `window.YOJANA`
2. एक डिब्बा कॉपी करके नीचे पेस्ट करो, **`id` नई रखो** (जैसे `"naya-kaam"`).

| लाइन | मतलब |
|---|---|
| `status` | `"active"` = प्रयास जारी है, `"soon"` = आगे आने वाली, `"done"` = पूरी हो गई |
| `title` | योजना का नाम |
| `short` | एक लाइन का विवरण (Home पर यही दिखता है) |
| `summary` | पूरा विवरण (योजना पेज पर) |
| `details` | बिंदुओं की सूची |
| `target` / `raised` | लक्ष्य और जमा राशि, जैसे `"₹ 11,00,000"`. न दिखानी हो तो `""` |
| `link` | एक बटन, जैसे टीम पेज का (वैकल्पिक) |
| `pinned: true,` | Home पर भी दिखाने के लिए |

### 5.4 Home पर क्या दिखे (Pin करना)

Home पर योजनाएँ, सूचनाएँ और कार्यक्रम, तीनों में **सिर्फ़ वही चीज़ें दिखती हैं जिनमें `pinned: true,` लिखा हो।**

- **Pin करना:** उसके डिब्बे में `{` के ठीक नीचे नई लाइन `pinned: true,` लिख दो।
- **Unpin करना:** वह लाइन मिटा दो। चीज़ अपने पेज पर बनी रहती है।
- अगर किसी हिस्से में कुछ भी pinned नहीं है, तो **वह पूरा हिस्सा Home से अपने आप ग़ायब** हो जाता है।
- कार्यक्रम में सिर्फ़ **आने वाले** pinned कार्यक्रम दिखते हैं (अगले 3). तारीख़ निकल जाए तो वह Home से अपने आप हट जाता है।
- अभी सारी 5 योजनाएँ, Welcome वाली सूचना और 9 नवंबर का कार्यक्रम pinned हैं। जो न चाहिए उनसे `pinned: true,` हटा दो।

### 5.5 मंदिर के समय (दर्शन, अभिषेक, आरती)

1. ढूँढो: `timings:` (यह `window.SITE` में है)
2. चार समय **24 घंटे वाले रूप** में लिखो: सुबह 6:30 = `"06:30"`, शाम 7:30 = `"19:30"`.
   ```
   timings: { open: "06:30", abhishek: "07:30", aarti: "19:30", close: "21:00" },
   ```
3. समय के नीचे का नोट `timingsNote` में बदलो।
4. समय का डिब्बा पूरा छुपाना हो तो `showTimings: false`.

`window.LINKS` में हर लिंक quote के बीच पेस्ट करो। जिसका लिंक अभी नहीं है, उसे `""` रहने दो। उसका आइकन धुँधला दिखेगा और दबेगा नहीं।

### 5.8 ऊपर की सोने जैसी पट्टी (Banner)

`window.BANNER` में `text` (संदेश) और `link` (दबाने पर कौन सा पेज). हटानी हो तो `enabled: false`.

### 5.9 टीम में नाम जोड़ना

1. ढूँढो: `window.TEAM`
2. समूह के `members` में एक लाइन कॉपी करके नीचे पेस्ट करो:
   ```
   { name: "नाम", role: { hi: "पद", en: "Role" }, phone: "", photo: "" },
   ```
3. नाम, पद और फ़ोन बदलो। फ़ोन डालोगे तो दबाने पर कॉल लगेगा। न दिखाना हो तो `""`.
4. **फ़ोटो:** पहले फ़ोटो छोटी करके `images/team` में डालो (भाग 4), फिर `photo: "ramesh.jpg"` लिखो। फ़ोटो न हो तो नाम के अक्षर दिखते हैं।
5. नया समूह चाहिए तो पूरा `{ group: ..., members: [...] },` डिब्बा कॉपी करो।
6. **ट्रस्टी** वाला समूह अभी `hidden: true` से छुपा है। नाम तय होने पर वह लाइन हटा दो।
7. किसी एक व्यक्ति को हटाने के लिए उसकी पूरी लाइन मिटा दो।

### 5.10 दान की जानकारी (UPI, बैंक, QR)

> ⚠️ **यहाँ बहुत ध्यान रखो।** एक अंक की गलती से किसी का पैसा ग़लत जगह जा सकता है। बदलाव के बाद ट्रस्टी से दोबारा जँचवा लो।

ढूँढो: `window.DAAN`

| क्या | कैसे बदलें |
|---|---|
| पेज की शुरुआती लाइन, अतिरिक्त नोट | `intro`, `note` में (हिंदी और English) |
| UPI ID | `upiId: "..."` |
| QR फ़ोटो | नई QR फ़ोटो का नाम `upi-qr.png` रखकर `images` में अपलोड करो (भाग 4), पुरानी की जगह आ जाएगी |
| बैंक की जानकारी | `bank:` की हर पंक्ति `{ label: ..., value: "ICICI Bank" },` है। सिर्फ़ `value: "..."` बदलो। जिसमें `copy: true` है उसमें "Copy" बटन आता है (खाता संख्या, IFSC) |
| "मंदिर कार्यालय में" कार्ड | `inPerson` |
| पीली सावधानी लाइन | `disclaimer` (हटाना हो तो हिंदी और English दोनों `""`) |

कोई जानकारी खाली `""` छोड़ दो तो वह कार्ड अपने आप नहीं दिखता।

### 5.11 "नियमित दान और सेवा" के कार्ड

ढूँढो: `window.RECURRING`. हर कार्ड एक डिब्बा है:
```
{
  title: { hi: "...", en: "..." },   // कार्ड का बड़ा नाम
  when:  { hi: "हर महीने", en: "Every month" },   // ऊपर का छोटा टैग
  text:  { hi: "...", en: "..." },   // मुख्य विवरण
  how:   { hi: "...", en: "..." }    // नीचे की छोटी लाइन (कैसे जुड़ें / किससे बात करें)
},
```
जोड़ना, हटाना, छुपाना: भाग 2.3. कार्ड उसी क्रम में दिखते हैं जिस क्रम में फ़ाइल में हैं।

**तैयार खाली कार्ड:** फ़ाइल में 3 छुपे हुए कार्ड "दान 1", "दान 2", "दान 3" पहले से हैं। इस्तेमाल के लिए उसकी `hidden: true,` लाइन हटाओ और अपना टेक्स्ट लिख दो।

### 5.12 पुण्यार्जक, द्रव्य दान और ट्रस्ट की जानकारी

- **`window.PUNYARJAK`** (शांतिधारा): हर नाम की एक पंक्ति `{ date, kind, name }`. `kind` में `"saptahik"` या `"masik"`. एक तारीख़ पर कई नाम हों तो हर नाम की अलग पंक्ति। अभी सिर्फ़ **चालू महीना** दिखता है। हर महीना दिखाना हो तो `window.SITE` में `punyarjakCurrentMonthOnly: false`.
- **`window.DRAVYA`** (द्रव्य दान): `{ date, name }` की पंक्तियाँ। सूची खाली हो तो तालिका नहीं दिखती। किसी का नाम उसकी अनुमति से ही डालो।
- **`window.TRUST`** (ट्रस्ट / 80G): `items` की हर लाइन `{ label: ..., value: "" },` है। जो जानकारी है उसकी `value` में लिख दो, जैसे `value: "ABCDE1234F"`. **खाली `value` वाली लाइन नहीं दिखती**, और सब खाली हों तो "जानकारी जल्द जोड़ी जाएगी" दिखता है। नई लाइन के लिए एक लाइन कॉपी करके `label` और `value` बदलो। `note` में एक अतिरिक्त लाइन लिख सकते हो। पूरा हिस्सा हटाना हो तो `enabled: false`.

### 5.13 गैलरी: फ़ोटो एलबम और वीडियो एलबम

एलबम मतलब एक मौक़े की सारी फ़ोटो एक साथ (जैसे "दिवाली 2026"). हर एलबम की अपनी एक फ़ोल्डर होती है।

**स्टेप 1: फ़ोल्डर बनाओ और फ़ोटो डालो**
1. GitHub में `images` → `gallery` खोलो।
2. **Add file → Create new file** दबाओ। नाम वाले डिब्बे में लिखो `diwali-2026/ruko.txt` (`/` लिखते ही GitHub फ़ोल्डर बना देता है)। नीचे **Commit changes**. अब `diwali-2026` फ़ोल्डर बन गई।
3. **फ़ोटो पहले छोटी करो** (भाग 4).
4. उस नई फ़ोल्डर में जाओ, **Add file → Upload files**, और छोटी फ़ोटो डालो (एक बार में 15-20), Commit करो। बाक़ी फ़ोटो के लिए यही दोहराओ।
5. फ़ोटो के नाम `01.jpg`, `02.jpg` जैसे (English, बिना space).

**स्टेप 2: एलबम का टेक्स्ट बनवाओ (सहायक पेज से)**
1. वेबसाइट के पते के आख़िर में `/gallery-helper.html` लगाकर खोलो।
2. **Photo album** में भरो: नाम (हिंदी और English), छोटा नाम (जैसे `diwali-2026`), तारीख़, और फ़ोल्डर (`images/gallery/diwali-2026`).
3. चुनो: **"Photo ke naam likhwana"** (फ़ोटो चुनो तो नाम अपने आप भर जाते हैं) या **"Folder ki saari photo site khud dikhaye"** (नाम लिखने की ज़रूरत नहीं).
4. **"Lines banayein"** दबाओ और नीचे बना हुआ टेक्स्ट कॉपी करो।

**स्टेप 3: `data.js` में चिपकाओ**
`window.GALLERY` ढूँढो। उसमें `photos: [` के अंदर, पहले एलबम `{ ... }` के बाद **कॉमा** लगाकर कॉपी किया हुआ टेक्स्ट पेस्ट करो। Commit करो।

**बिना सहायक पेज के (हाथ से):** किसी एलबम का पूरा डिब्बा कॉपी करके नीचे पेस्ट करो और बदलो:

| लाइन | क्या बदलना है |
|---|---|
| `id` | एलबम का छोटा अलग नाम, बिना space, जैसे `"diwali-2026"` |
| `date`, `title` | तारीख़ (साल-महीना-दिन) और नाम (हिंदी, English) |
| `folder` | `"images/gallery/diwali-2026"` (बड़े-छोटे अक्षर फ़ोल्डर के नाम जैसे ही) |
| `files` | `["1.jpg", "2.jpg"]`. **यह लाइन पूरी हटा दो** तो साइट फ़ोल्डर की सारी फ़ोटो खुद दिखा देती है |
| `cover` | (वैकल्पिक) कवर फ़ोटो, जैसे `cover: "images/gallery/diwali-2026/05.jpg",` |

**कवर और फ़ोटो की गिनती:** `files:` लाइन न हो तो साइट फ़ोल्डर देखकर गिनती ("50 फ़ोटो") और कवर (फ़ोल्डर की **पहली फ़ोटो**) अपने आप लगा देती है (1 सेकंड लग सकता है)। कोई ख़ास फ़ोटो कवर चाहिए तो ऊपर की `cover` लाइन जोड़ दो।

**वीडियो एलबम:** `gallery-helper.html` के **Video album** वाले हिस्से में नाम भरो और हर लाइन में एक YouTube लिंक डालो (चाहो तो लिंक के बाद `|` लगाकर नाम). बना हुआ टेक्स्ट `window.GALLERY` के `videos: [` के अंदर पेस्ट करो। अकेला वीडियो, playlist या चैनल, तीनों के लिंक चलते हैं और वीडियो साइट के अंदर ही चलता है।

**छुपाना:** एलबम (या किसी एक फ़ोटो/वीडियो) में `hidden: true,`.

### 5.14 Home की फ़ोटो पट्टी (स्लाइडशो)

`window.SITE` में `slideshow:` ढूँढो। लाइन ऐसी है:
```
slideshow: { enabled: true, source: "all", shuffle: false, count: 14, seconds: 4 },
```

| शब्द | क्या करता है |
|---|---|
| `enabled: true` / `false` | पूरी पट्टी चालू / बंद |
| `source: "all"` | सारे एलबम की फ़ोटो |
| `source: "Kshamavani-2026"` | सिर्फ़ उस एक एलबम की फ़ोटो। यहाँ एलबम की `id` लिखो, बड़े-छोटे अक्षर वैसे ही |
| `shuffle: false` / `true` | हर बार एक ही क्रम / हर बार अलग क्रम |
| `count: 14` | कुल कितनी फ़ोटो आएँ (पहली 14, या `shuffle: true` हो तो सब में से चुनी हुई 14) |
| `count: "all"` | एलबम की **जितनी भी फ़ोटो हैं सारी** (संख्या अपने आप गिन लेता है) |
| `seconds: 4` | हर कितने सेकंड में आगे बढ़े |

**उदाहरण: सिर्फ़ क्षमावाणी एलबम की सारी फ़ोटो एक-एक करके:**
```
slideshow: { enabled: true, source: "Kshamavani-2026", shuffle: false, count: "all", seconds: 4 },
```

**ध्यान:** `"all"` में दोनों तरफ़ quote लगाओ। एलबम में फ़ोटो पहले अपलोड हो, वरना पट्टी खाली रहेगी या Home से हट जाएगी। अभी `images/gallery/vedi-pratishtha/` में 5 नमूने की फ़ोटो (`sample-1.jpg` से `sample-5.jpg`) रखी हैं। असली फ़ोटो डालने के बाद उस एलबम की `files:` लाइन और ये sample फ़ोटो हटा दो।

### 5.15 "हमारे बारे में" और "कैसे पहुँचें"

**हमारे बारे में** (`window.ABOUT`): तीन हिस्से हैं:

| हिस्सा | पहचान (`id`) |
|---|---|
| मंदिर के बारे में | `"mandir"` |
| भगवान नेमिनाथ | `"bhagwan"` |
| दर्शन के नियम | `"visit"` |

1. `window.ABOUT` ढूँढो और हिस्से को उसकी `id` से पहचानो।
2. `paragraphs: [ ... ]` में हर पैराग्राफ़ ऐसा है: `{ hi: "...", en: "..." },`. `hi` और `en` दोनों का टेक्स्ट बदलो।
3. हिस्से का नाम (शीर्षक): `title: { hi: "...", en: "..." }`.
4. नया पैराग्राफ़ जोड़ना या हटाना: भाग 2.3 जैसे (हिस्से के `paragraphs` के अंदर).
5. **"दर्शन के नियम"** की सूची उसी हिस्से के `list: [ ... ]` में है। हर लाइन एक नियम: `{ hi: "मोबाइल साइलेंट रखें।", en: "Keep your phone on silent." },`. नियम बदलो, लाइन कॉपी करके जोड़ो, या मिटाओ।
6. उसके ऊपर के परिचय में "इन्हें अपने मंदिर के नियमों के अनुसार बदल लें" लिखा है। यह सिर्फ़ नमूना है। इसे और 5 नियमों की सूची को अपने मंदिर के असली नियमों से बदल दो।
7. चौथा हिस्सा चाहिए तो भाग 2.3 के हिसाब से पूरा हिस्सा कॉपी करो और `id` नई रखो। bullet points नहीं चाहिए तो `list` वाला भाग हटा दो।

**कैसे पहुँचें** (`window.HOWTO`): सड़क / रेल / हवाई मार्ग / पार्किंग के डिब्बे, हर एक `{ title, text }`. `hi`/`en` बदलो। पार्किंग वाला अभी `hidden: true` से छुपा है, दिखाना हो तो वह लाइन मिटा दो। पता, फ़ोन और नक्शा इसमें नहीं हैं, वे `window.SITE` में हैं (भाग 5.6).

### 5.16 जैन कैलेंडर (पर्व, कल्याणक, तिथि)

`window.CALENDAR` में हर तारीख़ एक डिब्बा है:

| लाइन | क्या लिखना है |
|---|---|
| `date` | तारीख़: साल-महीना-दिन |
| `type` | `"kalyanak"`, `"parv"`, `"tithi"` या `"other"` |

| `note` | तिथि और मंदिर में क्या होगा |

तारीख़ें किसी भरोसेमंद पंचांग से देखकर लिखो। अभी इसमें "SAMPLE" वाली तारीख़ें हैं, उन्हें असली से बदल दो या `hidden: true,` से छुपा दो।

### 5.17 नाम, एक लाइन का परिचय, लोगो, बड़ी फ़ोटो, "वेबसाइट निर्माता"

`window.SITE` में:
- **`name`, `place`:** मंदिर का नाम और जगह। नाम बदलो तो हर `.html` फ़ाइल के ऊपर की `<title>` वाली लाइन भी बदलो (Google और ब्राउज़र टैब वही पढ़ते हैं)।
- **`tagline`:** Home पर नाम के नीचे की लाइन (हिंदी, English).
- **`heroImage`:** (वैकल्पिक) Home के ऊपर पीछे की बड़ी फ़ोटो, जैसे `"images/hero.jpg"`. न चाहिए तो `""`.
- **`credit`:** फुटर का "वेबसाइट निर्माता": `credit: { name: "...", url: "..." }`. हटाना हो तो `credit: null`.

**लोगो बदलना:** नया लोगो वर्गाकार (square) PNG हो, जिसमें गोल निशान पूरा भरा हो और कोने पारदर्शी हों। उसका नाम `mandir-logo.png` रखकर `images` में अपलोड करो (भाग 4), पुरानी की जगह आ जाएगी। ब्राउज़र टैब के छोटे आइकन अलग फ़ाइलें हैं (`favicon-32.png`, `apple-touch-icon.png`, `icon-512.png`), लोगो बदलो तो इन्हें भी बदलो।

### 5.18 विज़िटर की गिनती और बाक़ी सेटिंग (`window.SITE` में)

| लाइन | क्या करती है |
|---|---|
| `goatcounter: "nemidham"` | फुटर में सबको दिखने वाली विज़िटर संख्या। नई वेबसाइट पर संख्या छोटी ही होगी और लोग आएँगे तो बढ़ेगी (कभी-कभी कुछ घंटे देर से दिखती है)। हटाना हो तो `""` |
| `analyticsId` | Google Analytics की ID। निजी आँकड़े (सिर्फ़ आपको) analytics.google.com पर दिखते हैं |
| `youtubeChannelId` | (वैकल्पिक) आपके YouTube चैनल की ID (`UC` से शुरू). भरने पर चैनल के सारे वीडियो गैलरी में चलते हैं और नए वीडियो अपने आप जुड़ जाते हैं। YouTube Studio → Settings → Channel → Advanced में मिलती है |
| `mapQuery` | (वैकल्पिक) जगह का नाम या coordinates। `mapEmbed` और `mapLink` पहले से भरे हैं, इसे छोड़ सकते हो |
| `github: { user, repo }` | आपका GitHub नाम और रिपॉज़िटरी का नाम। गैलरी की फ़ोटो अपने आप दिखाने के लिए ज़रूरी है। **रिपॉज़िटरी का नाम न बदला हो तो इसे मत बदलना** |
| `timezone` | भारत के लिए `"Asia/Kolkata"` ही रहने दो |

### 5.19 पेज के शीर्षक, मेन्यू और बटन के शब्द (`i18n.js`)

हर पेज के ऊपर का शीर्षक और उसके नीचे की एक लाइन, मेन्यू के नाम, बटन के शब्द और Home के दो नीचे वाले कार्ड का टेक्स्ट **`data.js` में नहीं, `js/i18n.js` में** हैं।

**स्टेप:**
1. GitHub में `js` → `i18n.js` खोलो → पेंसिल ✏️.
2. Ctrl + F से वह शब्द ढूँढो जो वेबसाइट पर दिखता है (जैसे `मंदिर के आने वाले काम`). फ़ाइल में वह **दो बार** मिलेगा: हिंदी वाले हिस्से में और English वाले हिस्से में।
3. quote के अंदर का टेक्स्ट बदलो, **दोनों भाषाओं में**. quote और कॉमा जैसे हैं वैसे रहने दो। लाइन में `{n}` जैसा कुछ हो तो उसे मत छेड़ो (वहाँ वेबसाइट अपने आप संख्या डालती है)।

| यह बदलना है | ढूँढने का नाम |
|---|---|
| किसी पेज का शीर्षक / नीचे की लाइन | `p.yojana.h1` / `p.yojana.lead` (योजना की जगह `karyakram`, `calendar`, `announcements`, `gallery`, `about`, `team`, `daan`, `visit`) |
| मेन्यू के नाम | `nav.` से शुरू होने वाली लाइनें |
| Home के दान और "कैसे पहुँचें" के कार्ड | `home.daan_h`, `home.daan_p`, `home.daan_btn`, `home.visit_h`, `home.visit_p`, `home.visit_btn` |
| Home के हिस्सों के शीर्षक और "सब देखें" | `home.yojana`, `home.notices`, `home.events`, `home.photos`, `home.yojana_all` आदि |

## 6. छुपाने / चालू करने (Hide / Enable) की सूची

| क्या छुपाना या चालू करना है | कैसे |
|---|---|
| सूचना, कार्यक्रम, योजना, कैलेंडर की तारीख़, गैलरी एलबम, टीम का समूह, नियमित दान का कार्ड, हमारे बारे में का हिस्सा, कैसे पहुँचें का डिब्बा | उसके डिब्बे में `hidden: true,`. चालू करने के लिए वह लाइन मिटा दो |
| टीम का एक व्यक्ति | उसकी पूरी लाइन मिटा दो |
| ऊपर की सोने जैसी पट्टी | `window.BANNER` → `enabled: false` |
| आज के समय का डिब्बा | `window.SITE` → `showTimings: false` |
| Home की फ़ोटो पट्टी | `window.SITE` → `slideshow: { enabled: false, ... }` |
| पूरा दान पेज | `window.DAAN` → `enabled: false` (तब "जानकारी जल्द आएगी" दिखता है) |
| UPI / बैंक / "मंदिर कार्यालय" का कार्ड | उसकी जानकारी खाली `""` छोड़ दो |
| ट्रस्ट / 80G | `window.TRUST` → `enabled: false` |
| पुण्यार्जक या द्रव्य दान की तालिका | सूची खाली `[ ]` कर दो |
| Home पर कोई योजना / सूचना / कार्यक्रम | `pinned: true,` हटा दो |
| फुटर का "वेबसाइट निर्माता" | `credit: null` |
| विज़िटर की गिनती | `goatcounter: ""` |

> मेन्यू से पूरा पेज (जैसे टीम या गैलरी) हटाना `data.js` से नहीं होता। पेज की सारी चीज़ें `hidden: true` कर दो तो पेज खाली दिखेगा। पूरा पेज मेन्यू से हटवाना हो तो किसी जानकार से कहो।

## 7. अगर कुछ गड़बड़ दिखे

- **वेबसाइट खाली या आधी दिख रही है:** लगभग हमेशा `data.js` में कोई कॉमा `,` या quote `"` छूट गया होता है। अपनी वेबसाइट के पते के आख़िर में `/check.html` लगाकर खोलो। वह साफ़ भाषा में बताएगा कि क्या ग़लत है।
- **बदलाव दिख नहीं रहा:** 2 मिनट रुको और **Ctrl + Shift + R** दबाओ।
- **कुछ बिगड़ गया, पुराना वर्शन वापस लाना है:**
  1. GitHub में रिपॉज़िटरी का पहला पेज खोलो और ऊपर **Commits** (घड़ी का निशान) दबाओ।
  2. वहाँ हर बदलाव की सूची है: किसने, कब, क्या बदला।
  3. जिस बदलाव ने गड़बड़ की, उस पर क्लिक करो और **Revert** चुनो। पुराना सही रूप लौट आएगा।

## 8. वेबसाइट सबको दिखाने (public करने) से पहले

1. `data.js` में **Ctrl + F** से **SAMPLE** ढूँढो। जहाँ-जहाँ मिले, असली जानकारी लिखो या वह डिब्बा `hidden: true` से छुपा दो।
2. **दान की जानकारी** (UPI, बैंक, QR) ट्रस्ट से ज़रूर जँचवाओ। यहाँ छोटी सी ग़लती से किसी का पैसा ग़लत जगह जा सकता है।
3. **फ़ोन नंबर और ईमेल** डाल दो।
